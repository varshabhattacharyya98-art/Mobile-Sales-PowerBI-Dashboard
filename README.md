# Mobile-Sales-PowerBI-Dashboard
An interactive Mobile Sales Dashboard in Microsoft Power BI to analyze and visualize mobile sales performance across different cities, brands, payment methods, and time periods. 
Implemented KPI cards, map visualizations, trend analysis, slicers, and DAX measures to generate actionable business insights and improve decision-making.
Created dynamic reports for sales trends, customer ratings, city-wise performance, and payment analysis.
**The dashboard helps stakeholders:**

Monitor total sales and quantity sold
Track monthly sales trends
Analyze city-wise performance
Compare mobile brands and models
Understand customer ratings
Evaluate payment method usage
Filter data dynamically for better decision-making
